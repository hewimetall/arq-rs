# ADR 0003. Python предлагает исход, Rust фиксирует переход

## Статус

Принято (2026-11-23).

## Контекст

Middleware simple-q может вернуть `retry` или заменить `dead` на другой outcome. Транспортный retry, ACK и lease при этом должны остаться у Rust. В доноре отсутствующий ключ `outcome` разбирается как успех, а неизвестная строка — как ошибка протокола. Документация донора описывает любой другой outcome как ACK. Это расхождение нельзя переносить молча.

## Решение

`dispatch` возвращает предложение. Rust записывает переход только при действующем владении, совпадении цикла и отсутствии блокирующей команды.

Допустимые предложения: `ok`, `skipped`, `retry`, `dead`. Отсутствие `outcome`, неизвестная строка, неверный тип или недопустимое поле дают причину DLQ `invalid_outcome`, если владение ещё действует. Исключение из `dispatch` даёт `dispatch_error` и не ставит неявный retry. Выход child до корректного результата оставляет доставку на lease recovery и не синтезирует исход handler.

## Последствия

Внешний middleware по-прежнему видит и может заменить словарь, который вернул внутренний слой. Замена действует только как новое предложение для Rust. Таблица исходов в `docs/operations.md` полная: реализация не добавляет третий смысл «неизвестное значит ACK».
